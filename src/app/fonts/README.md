# Fuentes locales

Los archivos WOFF2 se obtuvieron de Fontsource 5.3.0 y se versionan junto con
la aplicación para que la compilación no dependa de Google Fonts ni de una
descarga de fuentes durante el build.

- Montserrat: pesos 400, 500 y 600; estilo normal.
- Playfair Display: pesos 400, 600 y 700; estilos normal e itálica.
- Geist y Geist Mono: fuentes variables, peso 100–900; estilo normal.
- Solo se incluyen los subconjuntos latin y latin-ext.

Cada familia se distribuye bajo SIL Open Font License 1.1. Sus avisos están
en los archivos `LICENSE-*-OFL.txt` de esta carpeta.
